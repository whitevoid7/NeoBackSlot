# Changelog

## [1.1.0] - Unreleased

### Added

- Added Fabric 1.20.1 port.
- Added Back Slot and Belt Slot inventory support.
- Added HUD and inventory overlays.
- Added keybind swapping.
- Added third-person item rendering.
- Added in-game transform editor.
- Added global and per-item transform profiles.
- Added optional ModMenu config screen.
- Added config files under `config/neobackslot/`.
- Added configurable inventory and HUD slot position offsets.
- Added modded melee and ranged weapon compatibility helpers.

### Fixed

- Fixed shields being accepted by the Belt Slot.
- Fixed shield removal using the wrong sound.
- Fixed missing HUD and inventory overlay behavior during the initial Fabric port.
- Fixed missing sprite warnings from old atlas namespace references.

## [1.0.0]

- NeoForge stable release. Fabric port did not exist yet.

## [0.9.0-alpha]

- NeoForge alpha release. Fabric port did not exist yet.
